# LedgerMind

**AI-Powered Financial Document Intelligence using RAG**

LedgerMind is an intelligent system that allows users to upload financial documents (10-K reports, earnings calls, invoices, etc.) and ask natural language questions to get accurate, context-aware answers.

## Features (Planned)
- Upload and process financial PDFs
- Intelligent document chunking
- Semantic search using vector embeddings
- Answer generation using LLMs (RAG)
- Clean web interface

## Tech Stack (Planned)
- Python
- LangChain
- Vector Database (Chroma / FAISS)
- LLMs (Groq / OpenAI / Local models)
- Streamlit / Gradio
